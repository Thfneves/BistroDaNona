# 🍽️ BistroDaNona

## 📌 Sobre o Projeto

Em fevereiro, iniciei o desenvolvimento deste aplicativo com o objetivo de melhorar meu raciocínio lógico e criar algo mais estruturado e complexo para treino e portfólio. O **BistroDaNona** foi desenvolvido majoritariamente com **UIKit**, sendo o projeto mais desafiador que já construí até o momento. Trabalhei com diversos conceitos que antes conhecia apenas na teoria e os coloquei em prática em um projeto escalável.

## 🚀 Tecnologias e Conceitos Aplicados

- 📌 **Arquitetura:** MVVM (Model-View-ViewModel)
- 🎨 **Interface:** UIKit + Storyboard
- 📦 **Componentes Reutilizáveis:** Collection Views
- 🔄 **Programação Assíncrona:** Closures
- 🏗️ **Design Patterns:** Orientação a Objetos, Protocolos
- 🧪 **Qualidade de Código:** Testes Unitários
